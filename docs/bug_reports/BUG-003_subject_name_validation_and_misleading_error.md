# Отчет об ошибке: BUG-003

- **Title (Заголовок):** [DB Schema / API] Ошибка валидации CHECK-ограничения названия предмета с латиницей/спецсимволами и вводящее в заблуждение сообщение об ошибке в [app/main.py](../../app/main.py) при обращении к [01_schema.sql](../../docker/init-db/01_schema.sql)
- **Severity / Priority:** Major / High (Препятствует добавлению в систему учебных дисциплин, содержащих латиницу, цифры или спецсимволы, таких как "Язык C++", "Web-технологии", "Базы данных 2", а также возвращает некорректную ошибку пользователю)
- **Environment:** Docker Compose, FastAPI, PostgreSQL 16
- **Preconditions (Предусловия):** База данных развернута и инициализирована через [docker-compose.yml](../../docker/docker-compose.yml).
- **Steps to Reproduce (Шаги для воспроизведения):**
  1. Выполнить HTTP-запрос POST на создание предмета с латиницей или спецсимволами в названии:
     ```bash
     curl -s -X POST "http://localhost:8000/api/v1/subjects" -H "Content-Type: application/json" -d '{"name": "Язык C++", "hours_count": 72, "semesters_count": 1}'
     ```
  2. Проверить тело ответа и код состояния HTTP.
- **Actual Result (Фактический результат):**
  - Возвращается код состояния `400 Bad Request` с телом ответа:
    ```json
    {"detail":"Ошибка целостности: количество часов и семестров должно быть строго больше 0"}
    ```
  - Запись о предмете не добавляется в таблицу `subject`.
- **Expected Result (Ожидаемый результат):**
  - Предметы с названиями, содержащими латиницу, цифры или спецсимволы (например, "Язык C++", "Web-технологии"), успешно создаются.
  - В случае реального нарушения ограничений (например, отрицательное количество часов) возвращается корректное сообщение об ошибке, а при нарушении формата названия — сообщение о некорректном формате названия, а не о количестве часов.
- **Root Cause Analysis (Предполагаемая причина):**
  1. В файле DDL-схемы [01_schema.sql](../../docker/init-db/01_schema.sql) ограничение таблицы `subject` определено как:
     `name VARCHAR(150) NOT NULL CHECK (name ~ '^[А-Яа-яЁё\s]+$')`
     Регулярное выражение `^[А-Яа-яЁё\s]+$` допускает только буквы кириллицы и пробелы, запрещая латиницу, цифры и спецсимволы (например, `+`, `-`, `.`).
  2. В файле [app/main.py](../../app/main.py) в эндпоинте `POST /api/v1/subjects` блок `except IntegrityError` перехватывает абсолютно любые ошибки целостности (включая нарушение CHECK-ограничения на имя предмета) и жестко возвращает сообщение `"Ошибка целостности: количество часов и семестров должно быть строго больше 0"`, что вводит пользователя в заблуждение.
