# Отчет об ошибке: BUG-004

- **Title (Заголовок):** [DB Schema] Ошибка валидации CHECK-ограничения `teacher_last_name_check` при вставке преподавателя со сложной фамилией через дефис в [01_schema.sql](../../docker/init-db/01_schema.sql)
- **Severity / Priority:** Major / Medium (Препятствует добавлению в систему преподавателей со сложными/двойными фамилиями, содержащими дефис)
- **Environment:** Docker Compose, FastAPI, PostgreSQL 16
- **Preconditions (Предусловия):** База данных развернута и инициализирована через [docker-compose.yml](../../docker/docker-compose.yml).
- **Steps to Reproduce (Шаги для воспроизведения):**
  1. Выполнить HTTP-запрос POST на создание преподавателя с двойной фамилией через дефис:
     ```bash
     curl -s -X POST "http://localhost:8000/api/v1/teachers" -H "Content-Type: application/json" -d '{"last_name": "Склодовская-Кюри", "first_name": "Мария", "middle_name": "Саломея", "department": "Физика", "position": "Профессор"}'
     ```
  2. Проверить тело ответа и код состояния HTTP.
- **Actual Result (Фактический результат):**
  - Возвращается код состояния `400 Bad Request` с телом ответа:
    ```json
    {"detail":"Ошибка валидации: поля ФИО, кафедры и должности принимают только буквы русского алфавита"}
    ```
  - Запись о преподавателе не добавляется в таблицу `teacher`.
- **Expected Result (Ожидаемый результат):**
  - Преподаватель с двойной/сложной фамилией, содержащей дефис (например, "Склодовская-Кюри"), успешно создается.
- **Root Cause Analysis (Предполагаемая причина):**
  - В файле DDL-схемы [01_schema.sql](../../docker/init-db/01_schema.sql) ограничение таблицы `teacher` определено как:
    `last_name VARCHAR(100) NOT NULL CHECK (last_name ~ '^[А-Яа-яЁё]+$')`
    Регулярное выражение `^[А-Яа-яЁё]+$` допускает только буквы кириллицы и не содержит символ дефиса (`\-` или `-`), из-за чего валидация для фамилий с дефисом завершается ошибкой. Требуется исправить regex на `^[А-Яа-яЁё\-]+$`.
