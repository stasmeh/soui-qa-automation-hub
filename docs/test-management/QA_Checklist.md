## 1. 🗂 Модуль «Справочники» (Dictionaries & Master Data)
*Охватывает сущности: Специальность, Группа, Студент, Преподаватель, Предмет, Задание, Контрольная точка.*

- [x] **CRUD-операции:** Успешное создание, редактирование и удаление записей во всех справочниках с валидными данными. (🤖 **API**)
- [x] **Required Fields:** Система выдает ошибку (422/400) при попытке сохранения сущности без обязательных полей. (🤖 **API**)
- [x] **Regex Validation:** Блокировка ввода латиницы и спецсимволов в кириллических полях (ФИО, названия специальностей, кафедр). (🗄 **DB Check**)
- [x] **BVA & Type Validation:** Блокировка отрицательных значений и нуля (например, часы предмета), а также ввода текста в числовые поля. (🗄 **DB Check**)
- [x] **Уникальность (Unique):** Запрет создания дубликатов для уникальных полей (код специальности, шифр группы, номер студ. билета). (🗄 **DB Constraint**)
- [x] **Ссылочная целостность (Foreign Key):** Запрет удаления родительской записи, если на нее есть ссылки (например, удаление специальности, к которой привязана группа). (🗄 **DB Restrict**)
- [x] **Сортировка:** Корректная сортировка списков (по алфавиту, по группе). (🤖 **API**)

## 2. 📓 Модуль «Журнал успеваемости» (Journal Lifecycle)

- [x] **State Transition (Создание):** Успешная выдача задания студенту (создание записи). Поля "Оценка" и "Дата сдачи" по умолчанию `null`. (🤖 **API**)
- [x] **State Transition (Фиксация):** Успешное обновление записи: выставление оценки и даты сдачи. (🤖 **API**)
- [x] **Граничные значения (BVA) оценки:** Успешное сохранение оценки в диапазоне `[1; 60]`. Отказ в сохранении для `0`, `61`, отрицательных и нечисловых значений. (🗄 **DB Check** / 🤖 **API**)
- [x] **Валидация даты:** Проверка логики при попытке выставить дату сдачи из будущего времени. (🤖 **API**)
- [x] **Зависимости журнала:** Запрет удаления студента, преподавателя, задания или КТ, если они уже фигурируют в записях журнала. (🗄 **DB Restrict**)

## 3. 💼 Режим преподавателя «Работа» (Filtered Views)

- [x] **Контекстная фильтрация:** Журнал корректно отфильтровывает и показывает записи только для выбранной пары «Преподаватель + Предмет». (🤖 **API** / 💻 **UI**)
- [x] **Обязательность фильтров:** Система требует обязательного выбора Преподавателя и Предмета перед открытием журнала. (💻 **UI**)
- [x] **Smart-создание:** При добавлении записи из отфильтрованного вида поля «Преподаватель» и «Предмет» предзаполняются автоматически и блокируются для изменения. (💻 **UI**)
- [x] **Удержание контекста:** После добавления, редактирования или удаления записи фильтр не сбрасывается, пользователь остается в контексте выбранного преподавателя/предмета. (💻 **UI**)
- [x] **Дополнительные фильтры:** Корректная работа саб-фильтров по «Группе» и «Контрольной точке» внутри открытого журнала. (🤖 **API**)

## 4. 📊 Модуль «Отчёты и Сводная ведомость» (Reporting & Aggregations)

- [x] **Генерация файлов:** Успешное формирование текстовых отчетов (`.txt`) по студентам, предметам и сводным ведомостям. Открытие файла при активном флаге "Показать отчет". (💻 **UI**)
- [x] **Фильтрация ведомости:** Отчет корректно строится с учетом выбранных фильтров: по конкретной Группе, Предмету. (🤖 **API**)
- [x] **Фильтрация по датам:** Отчет корректно включает только те сдачи, которые попадают в заданный диапазон `start_date` / `end_date`. (🤖 **API**)
- [x] **Защита дат:** Обработка некорректного интервала (когда дата начала больше даты окончания) — сервис не падает, возвращается ошибка валидации. (🤖 **API**)
- [x] **Точность вычислений:** Средний балл (AVG) и количество контрольных точек (COUNT) рассчитываются математически верно. (🗄 **DB** / 🤖 **API**)
- [x] **Пустая выборка:** При отсутствии данных по заданным фильтрам формируется пустой отчет без системных ошибок. (🤖 **API**)
